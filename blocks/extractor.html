Extractor

The Extractor is a processing block added by Earthify.

It extracts oils, dyes and other valuable materials from various items using heat.

Obtaining

Extractor can only be obtained through crafting.

Crafting

Usage

Insert a valid ingredient into the left slot.

The Extractor will slowly process the item and place the extracted product into the output slot. Check this for tutorial how to add new Extractor recipes.
