How to create an Add-on (for Minecraft 26.2+ versions)

Earthify provides several tags that can be used by external add-ons. Before using them, add the Earthify Maven repository to your project.

1. Add Earthify Repository

Add the Modrinth Maven repository inside your build.gradle:

Gradle 
repositories {
    maven {
        name = "Modrinth"
        url = "https://api.modrinth.com/maven"
    }
}

2. Add Dependency

Add Earthify as a runtime dependency:

gradle.properties

Java Properties 
earthify_version=1.1.0 # Example version

build.gradle

Gradle 
dependencies {
    implementation "maven.modrinth:earthify:${earthify_version}"
}

3. Available Tags

The following tags can be used by your add-on to integrate with Earthify.

Tag Description
EarthifyItemTags.BERRIES Adds berries. Will be used as food for Raccoons (at least now)
EarthifyItemTags.BADGER_FOOD Adds new food items for Badgers.
EarthifyItemTags.DUCK_FOOD Adds new food items for Ducks.
EarthifyItemTags.PENGUIN_FOOD Adds new food items for Penguins.
EarthifyItemTags.CAPYBARA_FOOD Adds new food items for Capybaras.
EarthifyItemTags.RACCOON_FOOD Adds new food items for Raccoons.
EarthifyBiomeTags.HAS_SMALL_STABLE Adds biomes where Small Stable structures can generate.
EarthifyEntityTypeTags.BESTIARY Registers entities in the Bestiary and counts them for the "Animal Lover" advancement.

Example Usage

Java 
tag(EarthifyItemTags.BADGER_FOOD)
    .add(ItemIds.SALMON);

tag(EarthifyEntityTypeTags.BESTIARY)
    .add(EarthifyEntityTypeIds.MY_ANIMAL);

4. Plugin Extensions API

Earthify includes an extension system that allows add-ons to inject additional functionality without modifying the mod itself.

Loaded extensions can be viewed using:

Command 
/earthify extensions

The command lists all loaded extensions and their unique identifiers. For example:

Java 
@EarthifyExtension
public class ExampleExtension implements IModExtension {

    @Override
    public Identifier getExtensionID() {
        return Identifier.fromNamespaceAndPath("mod_id", "extension_name");
    }

    @Override
    public void registerAttributes(IAttributeRegistration registration) {
        registration.forItem(EarthifyItems.MIXTURE).add(Attributes.MOVEMENT_SPEED, 0.15,
            AttributeModifier.Operation.ADD_MULTIPLIED_TOTAL);
    }
}

Current Capabilities

The extension API is still under development. Currently, extensions are mainly intended for attribute customization.

Feature Description
Attribute Modifiers Add additional attribute modifiers to Mixture (for example) to enhance its power.

5. Extractor Recipes

Earthify provides a recipe builder for the Extractor, allowing add-ons to register extraction recipes through data generation.

The Extractor can extract items from blocks or other items. Extractor recipes are fully compatible with JEI, which displays the recipe, extraction duration, experience, and additional recipe information. They also integrate with Minecraft's Recipe Book, where recipes are automatically unlocked and a recipe toast is shown the first time the player obtains an item or block that can be extracted by the Extractor.

Example:

Java 
ExtractorRecipeBuilder.extractFrom(EarthifyItems.STRIPPED_ROSEWOOD_LOG).to(EarthifyItems.ROSEWOOD_OIL).extractionTime(300).experience(1F).category(ExtractorBookCategory.OILS)
    .unlockedBy(getHasName(EarthifyItems.STRIPPED_ROSEWOOD_LOG), has(EarthifyItems.STRIPPED_ROSEWOOD_LOG)).save(output);

Or just look for AbstractEarthifyRecipeProvider for needed extractor(...) helper.

Example of a generated JSON:

JSON 
{
  "type": "earthify:extractor",
  "category": "oils",
  "experience": 1.0,
  "ingredient": "earthify:stripped_rosewood_log",
  "extraction_time": 300,
  "result": {
    "id": "earthify:rosewood_oil"
  }
}

Features

JEI Support

Recipes are automatically displayed in JEI with the extraction duration and additional recipe information.

Recipe Toasts

When the player obtains an item that can be extracted in the Extractor for the first time, a recipe toast is displayed to indicate that a new extraction recipe has been discovered.

Custom Extracting Time

Recipes can define a custom extraction duration using .extractionTime(ticks). If not specified, the default extraction time is 1200 ticks (60 seconds).
