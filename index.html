Earthify

Earthify is a Minecraft mod inspired by Earth. The mod brings new mobs, items, blocks and biomes into modern Minecraft.

Earthify aims to preserve the unique content while integrating it naturally into vanilla gameplay.

If you want to contribute Earthify and want to create an Add-on check this page.

Features

  • Unique mobs
  • New decorative and functional blocks
  • Custom biomes
  • New items and resources
  • NeoForge support
