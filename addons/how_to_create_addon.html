How to create an Add-on (for Minecraft 26.2+ versions)

Earthify provides several tags that can be used by external add-ons. Before using them, add the Earthify Maven repository to your project.

1. Add Earthify Repository

Add the Modrinth Maven repository inside your build.gradle:

Gradle 
repositories {
    maven {
        name = "Modrinth"
        url = "https://api.modrinth.com/maven"
    }
}

2. Add Dependency

Add Earthify as a runtime dependency:

gradle.properties

earthify_version=1.1.0 # Example version

build.gradle

Gradle 
dependencies {
    implementation "maven.modrinth:earthify:${earthify_version}"
}

3. Available Tags

The following tags can be used by your add-on to integrate with Earthify.

Tag Description
ModItemTags.BERRIES Adds berries. Will be used as food for Raccoons (at least now)
ModItemTags.BADGER_FOOD Adds new food items for Badgers.
ModItemTags.DUCK_FOOD Adds new food items for Ducks.
ModItemTags.PENGUIN_FOOD Adds new food items for Penguins.
ModItemTags.CAPYBARA_FOOD Adds new food items for Capybaras.
ModItemTags.RACCOON_FOOD Adds new food items for Raccoons.
ModBiomeTags.HAS_SMALL_STABLE Adds biomes where Small Stable structures can generate.
ModEntityTypeTags.CAN_WALK_THROUGH_BUSH Allows entities to walk through berry bushes without taking damage.
ModEntityTypeTags.BESTIARY Registers entities in the Bestiary and counts them for the "Animal Lover" advancement.

Example Usage

Java 
tag(ModItemTags.BADGER_FOOD)
    .add(ItemIds.SALMON);

tag(ModEntityTypeTags.BESTIARY)
    .add(ModEntityTypeIds.MY_ANIMAL);

4. Plugin Extensions API

Earthify includes an extension system that allows add-ons to inject additional functionality without modifying the mod itself.

Loaded extensions can be viewed using:

Command 
/earthify extensions

The command lists all loaded extensions and their unique identifiers. For example:

Java 
@EarthifyExtension
public class ExampleExtension implements IModExtension {

    @Override
    public Identifier getExtensionID() {
        return Identifier.fromNamespaceAndPath("mod_id", "extension_name");
    }

    @Override
    public void registerAttributes(IAttributeRegistration registration) {
        registration.forItem(ModItems.MIXTURE).add(Attributes.MOVEMENT_SPEED, 0.15,
            AttributeModifier.Operation.ADD_MULTIPLIED_TOTAL);
    }
}

Current Capabilities

The extension API is still under development. Currently, extensions are mainly intended for attribute customization.

Feature Description
Attribute Modifiers Add additional attribute modifiers to Mixture (for example) to enhance its power.
