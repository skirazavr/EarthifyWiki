Version History

This page contains the complete changelog for every public release of Earthify.

1.1.5 (Latest)

Added

  • Quivers (You can use it as holder for Arrows and use it within Quiver)
  • Colors of the Rosewood Grove were updated to look more realistic
  • Provide Bestiary book with Discovered and Undiscovered animals (Dynamically updates itself when new animal added through tag or discovered by Player)
  • New Extractor recipe book categories. You can use them for your addons. If some categories are missed just open new issue at GitHub and I will add new category if it's useful

Fixed

  • Fix bug with extractor processing using recipe book
  • Fix bug with no horse at Small Stable

Removed

  • Remove CAN_WALK_THROUGH_BUSH entity tag

1.1.4

Added

  • Polish localization
  • Change back bestiary style to looks more cozy
  • Added the Extractor machine (be careful when step on top) with its own sound style and some new features
  • Added extractor recipes builder (check this to create a custom recipe for the Extractor)

1.1.3

Added

  • Ruby is a new trim material
  • Implemented a dynamic system that displays the Spawn Egg of each newly discovered mob (compatible with add-ons).
  • Added a new bestiary style.
  • Added rainbow wool and rainbow bed.
  • Added the ability to convert a Wolf into a Skeleton Wolf using a Rotting Potion.
  • Added new decorative blocks (introduced in 1.1.2 but previously undocumented).

Changed

  • Rosewood leaves are now biome-tinted.
  • Tamed Wolf data is now preserved when converting to a Skeleton Wolf.

1.1.2

Added

  • Added Survival Tests (beta).
  • Added Penguins, Capybaras and Raccoons (also required for the Bestiary).
  • Added the ability to tame Capybaras using Glistering Melon Slices.
  • Added new tags for add-on creators.
  • Added the Stench effect and its corresponding potion (currently unused).

Changed

  • Renamed and changed the trigger for the "Rotted to the Core" advancement.
  • Furnace Golems can now be created using Iron Blocks and a Blasting Furnace.
  • The Rotting effect now affects all non-undead entities.
  • Various other changes and improvements.

1.1.1

Added

  • Introduced the Extension System (Work in Progress).
  • Added Survival Tests (alpha).
  • Added a new Feature Flag system for enabling experimental gameplay features.
  • Added new secret achievements for Survival Tests.
  • Added an in-game update notification system.
  • Added new achievements.
  • Added statistics for feeding Badgers and Ducks.
  • Added new sounds for Badgers.

Changed

  • Retextured several items.
  • Renamed item IDs from duck_meat to duck and cooked_duck_meat to cooked_duck for better vanilla consistency.
  • Survival Tests are experimental and may be changed, renamed or removed before release.

Removed

  • Removed Vampirism, as similar functionality is already provided by other mods.

Fixed

  • Fixed the Moolip and Moobloom flower layer rendering.

1.1.0

Added

  • Added the Bestiary system with discovery toasts for all Earthify animals.
  • Added a new effect system.
  • Added a new heart type after drinking Mixture.
  • Added the Rosewood Grove biome.
  • Added Rosewood trees with logs, planks, boats and other wooden variants.
  • Added a small Stable structure that generates in Rosewood Grove biomes.
  • Added Raspberry Bushes, exclusive to Rosewood Grove.
  • Added the Vampirism enchantment, which steals health with every hit.
  • Added Beehive variants for every wooden plank type.

Changed

  • Mixture now permanently grants up to 10 additional hearts and uses the new heart type.
  • Added Belarusian (Latin) (be_latn) and Ukrainian (uk_ua) translations.
  • Updated several advancements.
  • Introduced the new LEGENDARY item rarity.
  • Renamed Frost Flower to Winter Flower.
  • Renamed frosted grasses to frozen variants.
  • Winter Flower and Mahonia Berries are now LEGENDARY items.
  • Winter Flower is now required to craft Mixture.
  • Ducks no longer lay eggs while swimming.
  • Beehives now naturally generate only in Plains, Taiga and Savanna villages.
  • Vanilla Beehives can now only be crafted using Oak Planks.

Removed

  • Removed the old update notification system. (for 26.2+)

Fixed

  • Fixed numerous bugs and stability issues.

This is the latest version for 26.1.2

1.0.8

Added

  • Added the Beekeeper villager profession.
  • Added the Beehive Place village structure.
  • Added new trades for the Beekeeper.

Changed

  • Beekeepers now use Beehives as their job site block.
  • Beekeepers now wait for honey before harvesting Beehives with Shears.
  • Mahonia Bushes can no longer be grown with Bone Meal.
  • Reduced the growth rate of Mahonia Bushes.
  • Mixture is now the toughest item in the world.
  • Beehive Places now generate only in Plains, Taiga and Savanna villages.

Fixed

  • Fixed a server crash at runtime.

1.0.7

Added

  • Added Rice as a village crop.
  • Added crops to chest loot tables.
  • Added Mixture (beta).
  • Introduced the new MYTHICAL item rarity.

Changed

  • All new flowers and crops can now be composted.
  • Some flowers and grasses can now be used as furnace fuel.
  • Mahonia can no longer be obtained through villager trading.
  • Mahonia is now classified as a MYTHICAL item.

Fixed

  • Fixed various translation issues.

1.0.6

Added

  • Added a new advancement.
  • Added new items to villager trades.
  • Added Cauliflower, Rice and Radish crops.
  • Added the Wanderer painting.
  • Added Mahonia Bushes with berries.
  • Added Petunia flowers and their potted variants.

Changed

  • New crops now generate in Plains and Desert villages.
  • Rice now naturally grows in Swamps on water.

Removed

  • Removed Sludge due to numerous bugs.

Credits

  • Thanks to PlatinumG17 (Matt C) for creating the Wanderer painting.
  • Thanks to Kaupenjoe for tutorial references and guidance.

1.0.5

Added

  • Added fog and unique particles for Sludge.
  • Added ambient sounds for flowing Sludge.
  • Added the Sludge Walker enchantment.
  • Added loot table and villager trade support for Sludge Walker (beta).
  • Added a new advancement.
  • Added new items to villager trades (beta).

Changed

  • Renamed Mud to Sludge. Breaking change: existing worlds must be recreated to generate the new Sludge lakes.
  • Updated Sludge lake biome generation.
  • Improved several translations to better match vanilla Minecraft.

Removed

  • Removed unused translations.

Fixed

  • No bug fixes in this release.

Known Issues

  • Sludge does not yet behave exactly like water. Waterfalls and similar mechanics may not work correctly.

1.0.4

Added

  • Added Mud Lakes.

Changed

  • Updated the Lavender texture.

Fixed

  • Fixed blocks that should not have BlockItems.
  • Fixed the Potted Lavender texture.

1.0.3

Added

  • Implemented update notification system.

1.0.2

Added

  • Ruby Blocks can now be used as Beacon base blocks.

Changed

  • Improved data generation to better match vanilla Minecraft.

1.0.1

Added

  • Added new sounds for the mod's achievement system.
  • Added new sounds for Lobber and Bouldering Zombies.

Changed

  • Updated Earthify to NeoForge 26.1.2.20-beta+.
  • NeoForge 26.1.2.20-beta is now the minimum required version.
  • Updated several translation strings.

Fixed

  • Updated chest loot tables to better match vanilla Minecraft.
  • Fixed Rabbit Foot drops from Jumbo Rabbits.

1.0.0

  • Initial release.
